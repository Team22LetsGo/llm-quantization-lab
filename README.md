# LLM Quantization Lab

한국어와 영어에서 4bit LLM 양자화가 언어 모델 품질에 미치는 영향을 비교하고, 한국어 평가 결과에 따라 후속 연구 방향을 정하기 위한 실험 저장소입니다.

## 예비 실험 목표

Qwen2.5-1.5B-Instruct를 대상으로 다음 조건을 비교합니다.

- FP16 기준 모델
- RTN 4bit 양자화
- 영어 Wikipedia 보정 데이터를 사용한 GPTQ 4bit
- 한국어 Wikipedia 보정 데이터를 사용한 GPTQ 4bit

한국어는 Wikipedia, 영어는 WikiText-2 평가 데이터를 사용해 Perplexity를 측정합니다. 언어별 데이터의 Perplexity 원점수를 서로 직접 비교하지 않고, 각 언어에서 FP16 대비 상대적인 Perplexity 증가율을 비교합니다. 여러 평가 표본에서도 결과 방향이 일관적인지 확인합니다.

## 예비 결과 이후

예비 실험 결과를 검토한 뒤 다음 중 하나를 후속 연구의 중심으로 정합니다.

1. 4bit 양자화에서 한국어와 영어의 성능 저하 차이 분석
2. 한국어 보정 또는 혼합 정밀도 방식으로 한국어 품질 저하를 줄이는 방법 탐색

혼합 정밀도 실험은 예비 결과가 이를 뒷받침할 때 진행합니다. Attention 헤드 분석과 스마트폰 실행은 후속 범위가 정해진 뒤 우선순위를 결정합니다.

# LLM Quantization Lab

`Qwen/Qwen2.5-1.5B-Instruct`의 4bit 양자화가 한국어와 영어의 다음 토큰 예측에 미치는 영향을 비교합니다. 예비 결과를 바탕으로 후속 연구 방향은 **한국어 품질 개선**으로 정했습니다.

## 헤드 분석

[`헤드분석_Qwen2.5-1.5B_Colab.ipynb`](헤드분석_Qwen2.5-1.5B_Colab.ipynb)은 새 Colab GPU 런타임의 기본 패키지로 실행합니다. 이전 노트북의 `transformers` 설치 셀을 실행했다면 런타임을 재시작하세요. `pilot_results/pilot_samples.json`을 업로드하면 1.5B FP16 모델의 레이어와 헤드를 차례로 탐색하고, 1번 평가 묶음에서 찾은 후보를 2·3번 묶음으로 검증합니다. 실행이 끝나면 결과 CSV를 브라우저로 다운로드합니다. 노트북에는 실행 결과가 포함돼 있지 않습니다.

실행 결과는 [`head_analysis_results`](head_analysis_results)에 저장했습니다. `head_layer_screen.csv`는 28개 레이어, `head_screen.csv`는 선정된 6개 레이어의 72개 헤드에 대한 탐색 결과입니다. 탐색에는 언어별 1번 묶음의 512토큰을 사용했습니다. `head_validation_by_group.csv`는 상위 10개 헤드를 사용하지 않은 2·3번 묶음(각 8192토큰)에서 다시 측정한 결과이고, `head_validation_summary.csv`는 두 묶음 평균입니다. `head_run_info.csv`에는 모델·환경·입력 표본 SHA-256이 있으며, 해시는 `pilot_results/pilot_samples.json`과 일치합니다.

아래 수치는 **헤드 하나만 끈 경우**의 검증 묶음 평균입니다. 변화율은 같은 언어·묶음의 FP16 기준 PPL에 대한 상대 변화이고, `S = 한국어 변화율 − 영어 변화율`입니다. 헤드 번호는 0부터 셉니다.

| 레이어·헤드 | 한국어 PPL 변화율 | 영어 PPL 변화율 | S (퍼센트포인트) | S가 양수인 검증 묶음 |
| --- | ---: | ---: | ---: | ---: |
| 0·10 | +64.06% | +18.72% | +45.34 | 2/2 |
| 0·8 | +36.25% | +10.69% | +25.56 | 2/2 |
| 0·2 | +13.67% | +3.74% | +9.93 | 2/2 |
| 0·7 | +13.52% | +4.44% | +9.09 | 2/2 |

검증한 10개 헤드 모두 한국어 PPL이 두 묶음에서 증가했고, 9개는 두 묶음 모두에서 S가 양수였습니다. 0·10의 S는 묶음 2에서 +53.96%p, 묶음 3에서 +36.73%p였고, 0·8은 각각 +34.11%p, +17.01%p였습니다. 이 둘은 **한국어 상대 민감도 후보**입니다. 단, 1번 묶음에서 6개 레이어와 10개 헤드를 고른 뒤 2·3번 묶음으로 검증했으므로 탐색에서 제외된 헤드는 평가하지 않았습니다. 마스킹은 FP16 모델의 출력에 대한 개입이며, 한국어 전용 기능이나 해당 헤드를 8bit로 보존했을 때의 품질 개선을 입증하지 않습니다. 한국어 Wikipedia와 영어 WikiText-2의 PPL 원점수도 직접 비교하지 않습니다.

## 예비 실험

[`예비실험_Qwen2.5-1.5B_Colab.ipynb`](예비실험_Qwen2.5-1.5B_Colab.ipynb)은 Colab T4에서 FP16, RTN 4bit, 영어 Wikipedia 보정 GPTQ 4bit, 한국어 Wikipedia 보정 GPTQ 4bit를 비교합니다. GPTQ 보정 문서는 언어별 128개이며 각 문서의 최대 512토큰을 사용합니다. 평가는 한국어 Wikipedia와 영어 WikiText-2 test에서 각각 3개 묶음, 묶음당 16개의 512토큰 구간으로 수행합니다.

지표는 Perplexity(PPL)와 같은 언어·평가 묶음의 FP16 대비 저하율 `D(%) = (양자화 PPL / FP16 PPL - 1) × 100`입니다. 아래 수치는 [`pilot_results`](pilot_results)의 CSV 24행에서 계산한 언어별 3개 묶음 평균입니다.

| 조건 | 한국어 PPL | 한국어 D | 영어 PPL | 영어 D |
| --- | ---: | ---: | ---: | ---: |
| FP16 | 9.55 | 0.00% | 13.79 | 0.00% |
| RTN 4bit | 12.00 | 25.72% | 16.32 | 18.26% |
| GPTQ 영어 보정 4bit | 11.62 | 21.75% | 14.90 | 8.05% |
| GPTQ 한국어 보정 4bit | 10.15 | 6.22% | 15.48 | 12.22% |

한국어 보정 GPTQ는 영어 보정 GPTQ보다 한국어 평가 PPL이 세 묶음 모두 낮았습니다(약 11.8~14.0% 개선). 대신 영어 평가 저하율은 8.05%에서 12.22%로 높아졌습니다. 평가 말뭉치가 서로 다르므로 한국어와 영어의 **PPL 원점수는 직접 비교하지 않습니다**. 이 결과는 세 묶음의 예비 PPL 평가이며 실제 대화 품질이나 다른 과제의 개선을 입증하지 않습니다.

`pilot_results/pilot_samples.json`에는 이번 비교에 사용한 보정 문서와 평가 문서가 저장돼 있습니다. `pilot_results/ppl_by_group.csv`에는 묶음별 결과가 있고, 같은 폴더의 `ppl_summary.csv`, `language_gap_summary.csv`, `korean_calibration_effect.csv`, `runtime.json`에는 요약과 실행 환경이 있습니다.

## 후속 실험: 한·영 64:64 혼합 보정

[`혼합보정_Qwen2.5-1.5B_Colab.ipynb`](혼합보정_Qwen2.5-1.5B_Colab.ipynb)은 **기존 표본을 재사용해 새 GPTQ 4bit 모델 하나만** 만듭니다. `pilot_samples.json`에서 영어 보정 문서 앞 64개와 한국어 보정 문서 앞 64개를 고정 시드로 섞습니다. 전체 보정 문서 수 128개와 GPTQ 설정(`bits=4`, `group_size=128`, `sym=True`, `desc_act=False`)은 예비 실험과 같습니다. 저장된 한국어·영어 평가 묶음에 대해 각각 PPL을 계산하고 기존 FP16·영어 보정·한국어 보정 결과와 비교합니다.

Colab에서 GPU 런타임을 선택하고 노트북을 순서대로 실행합니다. 업로드 창에서 [`pilot_results/pilot_samples.json`](pilot_results/pilot_samples.json)과 [`pilot_results/ppl_by_group.csv`](pilot_results/ppl_by_group.csv) **두 파일**을 선택합니다. 결과는 `mixed_64_64_results.zip`으로 컴퓨터에 다운로드됩니다. Google Drive 연결은 필요하지 않습니다. 모델 체크포인트는 Colab 런타임에만 남으므로 런타임이 종료되면 사라질 수 있습니다.

Colab T4 실행 결과는 [`mixed_64_64_results`](mixed_64_64_results)에 저장했습니다. `mixed_ppl_by_group.csv`에는 한국어·영어 각각 3묶음의 결과 6행이, `comparison_summary.csv`에는 기존 조건과 혼합 보정의 언어별 평균이, `mixed_runtime.json`에는 실행 설정과 입력 파일 해시가 있습니다. 해시가 `pilot_results`의 두 입력 파일과 일치합니다.

| GPTQ 4bit 보정 데이터 | 한국어 PPL | 한국어 D | 영어 PPL | 영어 D |
| --- | ---: | ---: | ---: | ---: |
| 영어 128개 | 11.62 | 21.75% | 14.90 | 8.05% |
| 한국어 128개 | 10.15 | 6.22% | 15.48 | 12.22% |
| 영어 64개 + 한국어 64개 | 10.26 | 7.47% | 15.03 | 9.01% |

혼합 보정은 한국어만 보정한 모델보다 한국어 저하율이 1.25%p 높았지만 영어 저하율은 3.21%p 낮았습니다. 영어만 보정한 모델과 비교하면 한국어 저하율이 14.28%p 낮고 영어 저하율은 0.96%p 높았습니다. 이 방향은 세 평가 묶음 모두에서 같았습니다. 따라서 혼합 보정은 두 언어 사이의 절충안이지만, **한국어 PPL만 보면 한국어 전용 보정이 가장 좋았습니다**. 세 묶음의 PPL 결과만으로 실제 한국어 대화 품질이나 일반적인 개선을 단정하지 않습니다.
